# 接骨院・整体向け AI 統合運営パッケージ（仮称: ClinicOne）

接骨院・整体院の「問診 → 施術 → 会計 → 口コミ獲得 → 再来促進 → 売上分析」までを
**一人でも回せる**ように、AI エージェントと業務システムをまるごと一つのパッケージに
したオールインワン SaaS。既存の口コミツールを本製品の 1 モジュールとして取り込み、
単品売りから**月額パッケージでのアップセル**への転換を狙う。
